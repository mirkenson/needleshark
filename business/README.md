# Страница для бизнеса — локальный прототип

Подготовлено 18 сентября 2026 года по ответам владельца. На VPS не опубликовано.

## Просмотр

```sh
python3 business/preview.py --port 4175
```

Адрес: http://127.0.0.1:4175/business/. Сервер слушает только loopback, отправка реальных заявок отключена. При попытке отправки выводится честное сообщение о недоступной отправке в предпросмотре.

`business/render.py` копирует действующий `dist` в `/tmp/needle-shark-business-preview`, создаёт страницу из `business/index.html` и добавляет CSS/JS этого раздела. Изображения берёт из существующего манифеста через `site_utils.image_attributes`, метаданные и внешние UTM — через `prepare_html`. Новые растровые изображения не создавались.

Только в копии предпросмотра пункт шапки «Для бизнеса» ведёт на `/business/`. На мобильной главной используется существующий тип меню каталога/блога, чтобы этот пункт был доступен. Остальная главная сохранена. Оглавление «Для бизнеса» внутри товара по-прежнему ведёт в его собственный раздел `#wholesale`. Все страницы копии получают `noindex,nofollow`, robots запрещает обход. Каталог публикации `dist` не содержит черновой страницы и заглушек цеха; `ops/deploy.sh` не публикует папку `business`.

## Согласованные условия

- Аудитория пока широкая: производство на заказ, партии своих изделий, ткани и стропы. Не выдумывать приоритетные сегменты и клиентские кейсы.
- Расчёт — за один рабочий день после уточнения данных менеджером.
- Готовые изделия — партиями от 20 штук. Уникальные изделия, размеры партии и темп серии согласуются индивидуально; универсальная мощность 1000 шт./месяц не обещается после уточнения владельца.
- Начать можно с образца, фото, идеи или готовых лекал. Разработка входит в стоимость партии. Пробная партия при необходимости оплачивается, как серийная; одинаковая цена единицы не заявляется.
- Можно пришивать бирки заказчика. Работа с его тканью зависит от материала и способа доставки.
- Менеджер, удобный заказчику канал, фото/видео и точки связи по брифу. Контроль по собственным или согласованным стандартам заказчика.
- В наличии для продажи Oxford 210D PU 2000, брезенты, спанбонды. Другие ткани — под объём заказа, обычно за несколько дней, с уточнением срока. Параметры и минимальный отрез строп не выдуманы.
- Договор и индивидуальная предоплата. Доставка по России удобной заказчику логистической компанией; самовывоз из Санкт-Петербурга.
- В блоке цеха две согласованные владельцем заглушки. Заменить реальными фотографиями до публикации. Нынешние фото изделий — прежние визуализации каталога, не доказательство новых B2B-кейсов.

## Форма и аналитика

Повторно используется `dist/script.js` и существующий `/api/leads`. Новое поведение включается только для `form[data-context=business]`. Дополнительные поля: необязательное направление и компания/сфера деятельности. Компания и направление добавляются текстом в `question`; `source_path=/business/`, `inquiry_type=wholesale` для партий/разработки, `direct` для материалов. Максимальная длина описания 4000, компании 160: итог помещается в серверный лимит 5000 с контекстом. API/БД/Google не менялись.

Для бизнес-формы добавлены проверка контакта и совпадения ID ответа. Повтор после потери ответа сохраняет ID при неизменных данных. Успех только после `ok: true` с тем же ID. Старые формы сохраняют прежний интерфейс и сценарии.

Подключены действующий `metrika.js` (112428810) и `analytics.js`. Используются существующие цели `request_open`, `form_start`, `form_submit_attempt`, `lead_submitted`, `ui_click`, `contact_click`, `outbound_click`; новые определения в кабинете не требуются. События B2B различимы по `page=/business/`, `context=business`. Табы — `ui_click` / `element=business_material`; выбор направления — `business_intent`; FAQ — `business_faq`. Программное заполнение формы не выдаётся за самостоятельный выбор пользователя. Начальная и повторная активация текущего таба не увеличивает счётчик.

В события не включаются контакт, название компании, текст заявки или файл. Форма исключена из записи содержимого Webvisor. Для анализа первых заказчиков компания/сфера доступна только в тексте заявки. Цель успешной заявки не означает продажу.

Входящие рекламные UTM остаются в URL при переходах к форме и читаются штатным счётчиком. Отдельное хранение атрибуции в CRM не добавлено. Внутренние ссылки без UTM. VK получает `utm_source=needle-shark.ru`, `utm_medium=referral`, `utm_campaign=website`, `utm_content=business_vk`. Ссылок на маркетплейсы на B2B-странице нет; существующая кампания Ozon в каталоге сохранена.

## Проверки

Основной отчёт: `docs/verification/20260918-business-prototype.json`.

Изолированный стенд для повторной проверки:

```sh
python3 business/qa_server.py
```

Адрес http://127.0.0.1:4176/business/. Подменяются только SDK Метрики и API внутри этого локального сервера. Принимаются только имена с префиксом «ТЕСТ» и контакты `@example.com`; вызывается действующая серверная валидация, без сохранения в БД, Google и отправки писем. Сценарии в `qa_case`: `wrong-id`, `error`, `retry` (первый ответ потерян), `slow` (отложенный ответ), `text200`, `without-scripts`. Тестовая панель выводит события только на QA-стенде и отсутствует в обычном прототипе.

Рабочая доставка заявки, кабинет и поступление B2B-целей в отчёты Метрики в этой задаче не проверялись. Перед публикацией потребуются фото, согласование результата, интеграция страницы/навигации в источники сайта, включение страницы в публичную подготовку/sitemap, актуальные версии общих ресурсов, проверенный коммит в GitHub и отдельный выпуск через `ops/deploy.sh`.

## Обновление визуалов и формы, 18 сентября 2026

Три категории примеров: чехлы, сумки, ремни; общий переход «Вся продукция» открывает каталог. Карточки растягиваются по высоте ряда, блок CTA прижат к низу через flex, без фиксированной высоты текста. В hero — предоставленный владельцем кадр с заменой маркировки машинок на JACK. Для категорий и пяти тканей созданы изображения ImageGen на белом студийном фоне. Это сгенерированные иллюстрации; они не подтверждают состав конкретного артикула или фактическое оснащение цеха.

Оптимизированные варианты 480/800/1280 px лежат в `business/assets/`, исходные генерации сохранены в каталоге ImageGen. Полные промпты, референсы и пути оригиналов — `docs/assets/business-image-prompts.json`. Дополнительные два фото производства всё ещё ожидаются; заглушки остаются только в прототипе.

Форма передаёт `business_intent` и `business_company` отдельно от задачи. Серверные изменения, миграция и закрытые ссылки на вложения описаны в `server/README.md`. Прототип на 4175 по-прежнему не отправляет реальные заявки.
