# Яндекс Метрика

Счётчик 112428810 подключён через общий `dist/metrika.js` на всех девяти HTML-страницах, включая каталог и блог. Шаблоны `blog/base.html` и `catalog/templates/base.html` автоматически подключают его для каждой новой статьи/товара. `noscript`-пиксель сохранён. Опубликована 11 сентября 2026, включая блог и первую статью. Включены webvisor, clickmap, trackLinks, accurateTrackBounce и ecommerce dataLayer по коду владельца. Ecommerce-события покупок пока не отправляются: заявки не являются оплаченными покупками.

В кабинете Метрики созданы цели типа JavaScript-событие:
- `ui_click`: нажатия ссылок, кнопок, checkbox и выбора файла; параметры element (data-track), page (путь).
- `form_start`: первое взаимодействие с формой на странице.
- `form_submit_attempt`: отправка валидной формы.
- `lead_submitted`: сервер подтвердил сохранение заявки. Это основная цель.

Идентификаторы элементов заданы явно в HTML, не менять их без необходимости. UTM применяются к внешним ссылкам: source=needle-shark.ru, medium=referral, content=элемент. Для Ozon обязательна campaign=vendor_org_211216 (включая динамические ссылки комплектаций и размеров); для VK сохраняется campaign=website. На внутренних ссылках, mailto и кнопках UTM не используются; для них предназначены события. Цели настроены 11 сентября, полный перечень и ID приведены ниже.

В событиях нет имени, контакта, текста заявки или имени файла. Форма имеет класс ym-hide-content для Webvisor. Cookie-уведомление информационное: счётчик загружается сразу по указанию владельца, кнопка «Понятно» только скрывает уведомление. Закрытие хранится в localStorage needle_cookie_notice=1; это не механизм отказа от аналитики. При очистке данных браузера уведомление появится снова.

Официальный API: https://yandex.ru/support/metrica/ru/objects/reachgoal

Основной домен с 11 сентября — `needle-shark.ru`; `www.needle-shark.ru`, `needleshark.ru` и `www.needleshark.ru` перенаправляют на него с сохранением пути и query. 13 сентября в кабинете счётчика 112428810 сохранены основной адрес `needle-shark.ru` и дополнительный `needleshark.ru`, приём только с указанных адресов и поддомены включены. Старый Sites-прототип `needle-shark-prototype.mirkenson.chatgpt.site` — отдельная площадка, не обновляется публикацией на VPS и не добавлена в разрешённые адреса Метрики. Новые пути `/blog/<slug>/` не являются поддоменами.

CTA внутри статей отправляет `blog_cta_click` с параметрами `article` (slug), `cta` (стабильный id блока), `page` (путь). URL назначения, текст материала и контакты в параметрах события не передаются. Соответствующая цель создана в кабинете; отправка события не доказывает покупку или подписку.

## Публикация 11 сентября: ссылки и события

`site_utils.py` размечает только внешние HTTP(S)-ссылки в тегах a: utm_source=needle-shark.ru, utm_medium=referral, utm_campaign=website, utm_content=стабильная метка. Существующие query-параметры (включая заданные UTM) и fragment сохраняются. Внутренние needleshark.ru/www, mailto/tel, скрипты/изображения/пиксели не меняются. Внешние ссылки на источники статьи также получают эту схему. Генераторы наследуют обработку; `ops/prepare-public.py` финализирует все HTML и sitemap.

Обработчик клика выбирает ровно одну категорию: blog_cta_click → contact_click → outbound_click → request_open → ui_click. Для внешнего CTA статьи приоритет у blog_cta_click. Значения контактов, query целевого URL, текст форм и персональные данные в событие не передаются. form_start/form_submit_attempt/lead_submitted сохраняются; последнее событие только после серверного подтверждения. Средняя кнопка мыши для ссылок также учитывается. Автоматические возможности Метрики сохранены; они не являются повторным вызовом пользовательского reachGoal.

При настройке 11 сентября в кабинете 112428810 были подтверждены основной адрес needleshark.ru, «Принимать данные только с указанных адресов» и «Включая поддомены». На момент начала настройки пользовательских целей не было. Создание и итоговая публичная проверка фиксируются в PROJECT_CONTEXT.md; исправление адресов 13 сентября описано ниже.

Восемь целей созданы и проверены в кабинете 11 сентября 2026 с условием «Совпадает»: blog_cta_click (611918849), outbound_click (611919368), contact_click (611919492), request_open (611920007), form_start (611920074), form_submit_attempt (611920219), lead_submitted (611920414), ui_click (611921224). Общий фильтр оставляет только трафик сайта и дополнительных адресов; «Не учитывать мои визиты» и поведенческая фильтрация роботов выключены. Настройки не расширялись на посторонние домены.

Для обычного перехода в той же вкладке обработчик дожидается callback reachGoal; запасной таймер 800 мс гарантирует переход даже при блокировке счётчика. Модификаторы клавиатуры, новые вкладки и загрузки сохраняют штатное поведение. Это уменьшает потерю цели при уходе со страницы, но не обходит блокировщики аналитики.
