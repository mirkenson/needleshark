### Где смотреть

В счётчике **Needleshark (second), 112428810** открыть «Цели»: «Клик CTA в статье» для CTA и «Клик по элементу сайта» для интерактивных блоков. В отчёте использовать цель, URL страницы и параметры визита `article`/`cta`/`element`/`block`; параметры позволяют выделять визиты с соответствующим действием. Несколько действий одного посетителя в одном визите могут попасть в несколько сегментов — не складывать такие сегменты как уникальных посетителей.
