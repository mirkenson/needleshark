# Передаваемое руководство Needle Shark

Версия 1.0 от 19 октября 2026. Самостоятельная визуальная база для нового специалиста и его агента; все существенные правила изложены внутри. Сайт и отправка писем этой задачей не изменяются.

## Готовые материалы

- `../../output/Needle-Shark-Visual-Knowledge-v1.zip` — комплект для передачи, 11 файлов.
- `../../output/pdf/Needle-Shark-Brand-Guide.pdf` — руководство на 11 страницах.
- `BRAND_KNOWLEDGE.md` — те же правила для базы знаний агента.
- `AGENT_INSTRUCTIONS.txt` — инструкция для его настройки.
- `START_HERE.txt` — порядок подключения и состав ресурсов.

Архив содержит только эти документы, исходный SVG, PNG логотипа для письма, два согласованных примера и два WOFF2 с лицензией. Внутренняя история, рекламные планы, клиентские данные и технические исходники сборки в архив не включаются. Снимки писем показывают дизайн; поля в КП остаются явно обозначенными. Фотографии товаров не включены: их добавляют к конкретному заданию.

## Источники правил

Основной источник — `docs/BRAND_GUIDE.md`, общий словарь `dist/theme.css`, актуальные `b2b/typography.css` и `b2b/site.css`, согласованные примеры `emails/previews/`. Копии логотипов, шрифтов и примеров проверены на побайтовое совпадение.

Ранняя Obsidian-концепция Industrial Minimalism / Clean Performance прочитана только для сверки. Её альтернативные шрифты, светлая палитра и крупные радиусы не представлены как текущая система. Личные бизнес-заметки не переносились. Примеры задания и схемы компоновки в руководстве обозначены как примеры, а не как новые утверждённые макеты.

## Сборка

Единый редактируемый источник — `knowledge.json`. `build.py` создаёт Markdown, TXT и автономный HTML для печати; `render.mjs` печатает HTML в PDF с встроенными ресурсами. Использован Chromium, чтобы сохранить точный исходный SVG и Manrope. После изменения значимого содержимого повторить визуальную проверку всех страниц.

Для авторского окружения нужны Python с fontTools/brotli (подготовка начертаний), Node с Playwright и установленный Google Chrome. Для проверки нужны Poppler и pypdf. Это инструменты подготовки документов; зависимости сайта не меняются.

1. `python3 docs/brand-handoff/prepare_fonts.py`
2. `python3 docs/brand-handoff/build.py`
3. `node docs/brand-handoff/render.mjs /absolute/path/to/playwright`
4. `pdftoppm -scale-to 1250 -png output/pdf/Needle-Shark-Brand-Guide.pdf tmp/pdfs/brand-handoff/final`
5. Просмотреть страницы и проверить извлечение текста, встраивание шрифтов, переносы и ресурсы.
6. `python3 docs/brand-handoff/package.py`

Статические TTF 400/700/800 получаются из исходных WOFF2 только во временной папке для надёжного PDF-экспорта. В комплекте сохраняются исходные веб-шрифты с лицензией. `tmp/pdfs/brand-handoff` — промежуточные HTML, TTF, PNG и диагностика; в Git и ZIP они не включаются.

Проверка 360/390/768/1024/1440, SEO, Метрики, форм, API и VPS не применяется к автономному документу: публичные страницы и интеграции не изменены. Подключение комплекта к конкретному агенту новым специалистом ещё не проверено.
