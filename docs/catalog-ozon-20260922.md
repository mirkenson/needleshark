## Просмотр и публикация

```sh
python3 catalog/render.py --preview
python3 server/preview.py --directory outputs/catalog-preview --port 4176
```

Предпросмотр: http://127.0.0.1:4176/catalog/. Все его HTML имеют `noindex,nofollow`, robots запрещает обход, SDK Метрики отключён, отправка реальных заявок отключена. Публичный `dist/catalog/` и sitemap включают только прежние три товара.

В `catalog/products.json` новые записи имеют `status: draft`. После проверки конкретной карточки сменить статус на `published`, выполнить обычную генерацию, все проверки публикации и отдельный выпуск через `ops/deploy.sh`. Папку `outputs/catalog-preview` в релиз не копировать.

Проверено: 15 catalog + 22 ops + 26 server тестов, публичная сборка 10 страниц, локальная сборка 33 HTML, 27 страниц каталога × 5 ширин, переключение всех 62 новых вариантов. Проверки формы с локальным тестовым ответом не подтверждают сохранение в PostgreSQL и доставку уведомления. Полный отчёт: [20260922-catalog-drafts.json](verification/20260922-catalog-drafts.json).
