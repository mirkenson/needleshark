# Изображения кейсов Needle Shark

26.10.2026: три визуализации чехла робота, предоставленные владельцем, аккуратно доработаны встроенным ImageGen. Изменение: более плотная, матовая и аккуратная чёрная ткань с широкими естественными складками. Геометрия робота, покрытые участки, ракурс, инструмент и фон сохранялись по заданию. Это не доказательство материала, жаростойкости или испытаний.

`robot-overall.png`, `robot-joint.png`, `robot-tool.png` — сохранённые результаты ImageGen. В `manifest.json` измеренные размеры, SHA-256, alt и варианты WebP 480/800/1448; PNG в preview/dist не копируются. Подготовка WebP — Pillow 12.3.0, quality=84, method=6; XMP сохраняется, когда присутствует. Исходные результаты не перезаписывались. Задания и промпты для воспроизведения — `image-prompts.txt`.

Все три кадра в кейсе имеют явное пояснение об ИИ. Необработанное исходное фото №4 не предоставлено и не имитируется. Технические данные заказа подтверждены владельцем отдельно в `posts.json.editorial`; изображение не является первичным техническим документом.
