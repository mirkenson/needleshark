# Блог Needle Shark

Страница `/blog/` и статьи `/blog/<slug>/` — статический HTML в стиле сайта. Источник материалов: `blog/posts.json`, общий шаблон: `blog/base.html`, генератор: `blog/render.py`. Зависимости не нужны. Пока согласованных статей нет, список пуст.

## Добавление материала из диктовки

1. Получить тему и факты от владельца, оформить связный текст. Не добавлять неподтверждённые свойства, цифры, отзывы и авторство. Вопросы о недостающих фактах решать до публикации.
2. Добавить запись в `posts.json` со статусом `draft`. Текст разбить на абзацы, смысловые подзаголовки и списки. Сначала показать владельцу текст; публикация на VPS — отдельный этап.
3. После согласования поставить `published`, указать фактическую дату публикации, запустить генератор, проверить страницу и навигацию в браузере. Сохранить проверенную версию в GitHub перед публикацией через `ops/deploy.sh`.

Формат записи (пример структуры, не готовая публикация):

```json
{
  "slug": "tema-stati",
  "status": "draft",
  "date": "2026-09-11",
  "title": "Согласованный заголовок",
  "description": "Краткое введение для списка и начала статьи.",
  "blocks": [
    {"type": "paragraph", "text": "Текст абзаца."},
    {"type": "heading", "text": "Подзаголовок"},
    {"type": "list", "items": ["Первый пункт", "Второй пункт"]}
  ]
}
```

`slug` уникален, содержит латинские строчные буквы, цифры и дефисы; опубликованный адрес сохранять. `date` — ISO-дата. Сортировка по дате, новые сверху. Разметка HTML в тексте экранируется. Черновики не создают публичных файлов. При переводе опубликованного материала в draft генератор удаляет только ранее созданную им страницу: не делать этого без явного решения о снятии публикации. `dist/blog/` вручную не редактировать. Новые типы блоков добавлять в общем генераторе по необходимости.

```sh
python3 blog/render.py
python3 -m unittest discover -s blog -p 'test_*.py'
python3 server/preview.py --port 4173
```

Ссылка на форму ведёт на существующую главную; новой формы и голосового ввода на сайте нет. Блог пока без счётчика Метрики, как каталог. `noindex,nofollow` сохранён. Для локального просмотра черновика можно вызвать `render()` с копией записи со статусом published и отдельным временным каталогом вне `dist/`; не коммитить тестовый контент.

## Подборка на главной

`featured: true` включает опубликованную статью в блок «Популярные статьи» внизу главной. Это редакционный выбор, не статистика просмотров. Показываются до трёх выбранных материалов, новые сверху. Черновики не попадают в подборку. Генератор обновляет только участок главной между `BLOG_FEATURED_START` и `BLOG_FEATURED_END`, остальная главная сохраняется. Пока подборка пуста, выводится краткое пустое состояние со ссылкой на блог.
