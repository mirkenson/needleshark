## Данные и общий шаблон

`products.json` — единственный источник товарных данных. `render.py` записывает готовые статические HTML в `dist/catalog/`; JavaScript не нужен для чтения описаний, размеров и FAQ. Главная не перегенерируется. Зависимостей и сборщика нет.

После изменения данных запустить из корня репозитория:

```sh
python3 catalog/render.py
python3 -m unittest discover -s catalog -p 'test_*.py'
python3 server/preview.py --port 4173
```

По умолчанию локальный просмотр не отправляет заявки. Для проверки действующей цепочки использовать `--live-api` и явно помеченные тестовые данные. В этом режиме форма действительно сохраняет заявку на VPS, в Google Sheets и отправляет уведомление.

- `order`: меньшее число ставит карточку выше.
- `visible: false`: убирает карточку из каталога, сохраняя товарную страницу и адрес.
- `seasonalNote`: пояснение временной недоступности на странице. Не оставлять покупателю ложное впечатление доступности: при сезонной паузе проверить и ссылки на площадки.
- `slug`: постоянный адрес. Для сезонного скрытия его не менять и запись не удалять.
- `sizes`: размеры в сантиметрах, в порядке владельца. Для этого прототипа приняты длина × ширина × высота по схеме исходной карточки 220 × 98 × 106.
- `sizeGuidance`: необязательные подсказки под размерами: `size`, `label`, `note`. Сопоставляются по тройке габаритов. Тип техники — приблизительный ориентир; марки и модели добавлять только при подтверждённой совместимости.
- `fastenings`: необязательные детали конструкции в блоке материала: `title`, `text`. У квадроцикла — резинка по низу и стяжка с фастексом, подтверждённые владельцем.
- `marketplaces`: название и `url`. `null` создаёт отключённую кнопку «Пока недоступно» без внешнего перехода. HTTPS-адрес создаёт внешний переход с `noopener noreferrer`. Привязку разных размеров к разным карточкам площадок согласовать отдельно.
- `images`: галерея; первая фотография используется в карточке и первом экране. Роли `hero`, `fit`, `material` задают фото для остальных блоков; без роли используется первая фотография.
- `copy`, `scenarios`, `faq`, `kit`, `materialText`, `fitNote`: содержание страницы. Продуктовые тексты вынесены из шаблона.
- `sections`: включённые блоки и их порядок. Оглавление и нумерация следуют этому списку. Смысловая основа: применение → материал → размер → комплект → вопросы → B2B. При отключении блока его данные пока сохраняются в записи.

Владелец одобрил структуру 10 сентября 2026 года. Следующие товары добавлять в этом же формате через общий шаблон: первый экран и покупка → сценарии → материал и конструкция → подбор размера → комплект → вопросы → обращение за партией. Содержание и нужные блоки могут различаться, но смысловой порядок и общий стиль сохраняются. Не создавать отдельную независимую вёрстку для каждого изделия.

Чтобы добавить следующий товар, скопировать запись, задать новый `slug`, содержание, фото, размеры и ссылки; выполнить генерацию и визуальную проверку. Текущий размерный блок рассчитан на изделия с тремя габаритами. Иные системы размеров потребуется добавить при появлении конкретного товара.

## Что делает форма сейчас

Кнопки открывают диалог с названием изделия, выбранным размером и типом обращения. Проверяются обязательные поля, email/телефон, целое положительное количество и чекбокс. `dist/catalog.js` отправляет запрос на существующий `/api/leads`; успех показывается только после подтверждения сохранения в PostgreSQL и очереди SQLite. На время запроса поля блокируются. После потери ответа повтор с тем же содержанием использует тот же UUID.

Поля `product_slug`, `product_name`, `product_size`, `inquiry_type`, `quantity`, `source_path` хранятся в отдельных nullable-колонках `orders`. В Google Sheets и письме они включаются в существующий текст «Задача». Файл в товарной форме не предусмотрен. Действующий `dist/script.js` главной не меняется. Установка и модель данных: `server/README.md`, `docs/DATABASE.md`.

Сквозной тест 10 сентября 2026 года: заказ №5, UUID `d917976b-db88-4669-a916-431a39ab20ca`. Браузер → PostgreSQL → очередь → Google Sheets: строка 7 содержит все поля, H7 — «Отправлено». Получение во входящие отдельно не проверялось. Данные теста явно помечены, не являются заказом.
