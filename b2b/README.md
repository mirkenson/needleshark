# B2B-рефакторинг — локальный прототип

Версия для просмотра владельцем, подготовлена 7–8 октября 2026 года. Основной сайт и `dist/` не меняются. Не публиковать `outputs/b2b-preview`: все страницы закрыты от индексации, аналитика и отправка заявок отключены.

## Просмотр

```sh
python3 b2b/render.py
python3 b2b/preview.py --port 4190
```

Открыть `http://127.0.0.1:4190/`. Сервер слушает только loopback. Остановить Ctrl+C после просмотра. Можно передать `--directory` для ранее собранного прототипа; включения реального API у этого сервера нет.

## Состав

- Главная с направлениями производства вместо отдельных товаров на первом экране. Доставка по России, расчёт от одного рабочего дня после уточнения данных, работа по ТЗ, сопровождение, гарантия 12 месяцев. Сразу следом — сохранённый блок Ozon: 80 000+ продаж, 4,9/5, 24 000 отзывов.
- Пять страниц `/napravleniya/`: `chehly`, `sumki`, `remni`, `ukrytiya-i-shtory`, `po-tz`. Применения, конструкция, ткани, исходные данные для расчёта, этапы, FAQ и форма.
- `/business/` с информацией о производстве и условиях заказа.
- `/catalog/`: 26 изделий из существующего `catalog/products.json`, поиск, фильтры, прямые ссылки на маркетплейс. Отдельные товарные HTML не создаются. `preview-redirects.json` содержит переходы старых адресов в каталог; локальный сервер сохраняет query и поддерживает `/index.html`.
- Общие шапка и футер с телефоном +7 911 128-51-32 и почтой info@neesha.ru. Telegram, MAX, WhatsApp, ВКонтакте — неактивные элементы по просьбе владельца, без вымышленных адресов.
- Форма: имя, почта, телефон, описание и прежнее согласие. Для связи достаточно почты или телефона; каждый заполненный контакт проверяется. Файлового поля нет, рядом объяснено, куда отправлять ТЗ и файлы.
- Сдержанные появления блоков, подсветка и движение элементов при наведении. Клавиатурные состояния и `prefers-reduced-motion` предусмотрены.

Существующие статьи и юридические тексты копируются в предпросмотр с общей навигацией. Исходники блога, каталога, бизнес-страницы, backend и рабочий релиз остаются прежними.

## Источники и подтверждённые данные

`content.json` хранит направления и материалы; `render.py` — общие шаблоны. Бренд, шрифт Manrope и цвет #BE3E3E взяты из действующего сайта. Изображения повторно используются из `business/assets/` и каталога: визуализации подписаны, они не выдаются за фотографии выполненных B2B-заказов. Новые фотографии и отзывы не выдумывались.

Телефон, пять преимуществ и гарантия 12 месяцев подтверждены владельцем в этой задаче. Коммерческие условия (разработка в стоимости партии, согласование уникальных заказов, готовые модели от 20 шт., платный образец) перенесены из ранее согласованного `/business/`. Показатели Ozon сохранены с действующей главной; новый аудит статистики магазина не проводился.

Справочные свойства тканей уточнены по первичным источникам, ссылки показаны рядом с материалами: FABREEX (Oxford), производитель брезента 37ru.net, CORDURA Classic и Spangroup (спанбонд). Плотность, состав, покрытие и свойства конкретной поставки нужно фиксировать при расчёте, а не переносить из произвольного артикула поставщика. Характеристики грузоподъёмных изделий требуют отдельного согласования; ремни сумок не объявляются стропами для подъёма грузов.

Референс структуры: [главная ПрофПошив](https://prof-poshiv.ru/) и [защитные чехлы](https://prof-poshiv.ru/zaschitnye-chehly/). Тексты, бренд и изображения референса не копируются.
